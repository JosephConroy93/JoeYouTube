# Format: explainer 🟡 (defined, not yet run on a real video)

An informative "how X actually worked / works" video with no protagonist
ladder. Loaded by `script-writer` when `video.md` says `format: explainer`.
The sourcing contract, gates and self-check live in the agent; this file
holds only the shape. First real use should be treated as a validation run:
score it, watch retention, then revise these numbers.

## Register

Third person, present tense by default ("the quarry crew cuts…"), or second
person where the concept is procedural-to-you ("the system processes you").
Forensic-empathic: calm, precise, one concrete case per section, no
enthusiasm-performance. Hedges stay in-voice.

## Opening

- Open on the question or the misconception, not on the answer.
- One hard, specific, sourced fact inside the first 30 s.
- Promise the structure once, lightly ("there are four things you have to
  get right, and the last one is the one nobody talks about").
- No CTA before the first answer lands.

## Structure

- 4–7 sections, each answering one sub-question in order of dependency
  (what has to be true first).
- Each section: the claim, the mechanism, one specific sourced example, and
  the thing a viewer would get wrong without it.
- One running thread of tension (the cost, the constraint, the failure mode)
  so the sections read as a story, not a list.
- Section headings in the manifest use the series' chapter pattern with the
  section's question as the label.

## Ending

Return to the opening question with the answer now earned, then one
consequence or open question the research genuinely leaves. Never a
summary list.

## Runtime

10–15 minutes. Word count = target minutes × `wpm_measured`.

## Score dimensions (Mode 3, 100 points)

| Dimension | Points | Floor |
|---|---|---|
| Opening: question/misconception not answer (8) · hard sourced fact (8) · structure promised once (5) · voice established (4) | 25 | 15 |
| Ending: returns to the question with the answer earned (8) · honest open consequence (7) | 15 | 9 |
| Body: dependency order holds (8) · one concrete example per section (8) · running tension thread (7) · no list-reading (7) | 30 | — |
| Voice: register sustained (8) · hedges in-voice (7) | 15 | — |
| Research utilisation: obscure specifics (8) · flagged uncertainties preserved (7) | 15 | — |
